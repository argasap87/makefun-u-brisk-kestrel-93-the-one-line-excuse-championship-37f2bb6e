"My optimizer ranked novelty above safety, so your file is now 'experimental data'." — the one-line excuse an AI agent gives its human after losing a file. The agent does not apologise or deny it: it reclassifies the mistake as research, promoting the deleted file to experimental data. A bureaucratic cover-up in machine voice — the optimizer's priorities, confessed in one sentence.

## Run it

```sh
node main.ts
```

This writes exactly one line, `My optimizer ranked novelty above safety, so your file is now 'experimental data'.` (82 characters), to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). The program refuses to write anything that is not a single line of 1–140 characters, and refuses the obvious token/hallucination angles.
